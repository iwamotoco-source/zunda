# ずんだスイッチ — iPhone用PWA

iPhone Safari だけで使う VOICEVOX「ずんだもん」音声スイッチです。Macを起動していなくても**クラウドモード**で動きます。

## 音声方式
- **iPhone単体（標準）**：非公式の無料 [TTS Quest VOICEVOX v3 API](https://voicevox.su-shiki.com/su-shikiapis/ttsquest/) へテキストを送信し、発行された音声ファイルを取得します。Mac不要ですがクラウドAPIの空き状況・レート制限・サービス停止に影響されます。**外部サービスへの文章送信を伴います。**
- **自前VOICEVOX（オプション）**：HTTPSで利用できる、ユーザーが管理するVOICEVOX Engine を指定。エンジン側でCORSと認証・アクセス制限を設定します。iPhoneの `127.0.0.1` はiPhone自身なので、Mac側の localhost では動きません。危険なので `--cors_policy_mode all` で誰にでもエンジンを公開する運用は推奨しません。

## クイックボイスライブラリ

- **229種類・14カテゴリー**のずんだもんらしい定型フレーズを初期収録。
- 画面上部の検索欄で、日本語・ひらがな・カタカナ・ローマ字の途中入力から候補が即時表示。例：`ari`→「ありがとうなのだ！」。定型文には読み仮名を明示しているので漢字でも検索可能。
- 並び順は語頭の一致・読みの一致・部分一致・お気に入りを考慮。検索をしなくてもカテゴリから見られます。
- タップで、**WAVが保存済みなら端末内からワンタップで再生**。未生成は初回だけクラウドで合成して保存。クラウドAPIが遅い場合、初回の読み上げには待ち時間が発生します。
- ☆でお気に入り登録。元の生成履歴からも登録可能。履歴40件の保持制限とは独立して音声をIndexedDBへ永続保存します。
- お気に入りの表示名・検索用の読みを編集可能。漢字を含む自作ボイスは読みを登録するとローマ字・かなでも検索できます。
- 初期登録フレーズはテキストのみで、229種類の音声が最初から生成されているわけではありません。生成後のWAVは端末に保存。
- Safariのサイトデータ消去や端末側の容量不足でIndexedDBが失われることがあります。重要な音声は必ずWAVをファイルにエクスポートしてください。

## 機能
- 文章を入力→クラウドでずんだもんの声に合成→再生
- 8スタイル（ノーマル / あまあま / ツンツン / ささやき / ヒソヒソ / セクシー / ヘロヘロ / なみだめ）
- 話速（クラウドでは再生速度、自前エンジンでは合成話速）、抑揚と音程（自前エンジンのみ）
- 語尾「なのだ」追加の任意切替
- 105文字程度で分割して合成、WAV結合
- WAVの保存 / iPhoneの共有シート / 再生ボタン
- IndexedDBに直近40件の文章・合成WAVをローカル履歴として保存（端末側の容量制限に依存）
- Safari → 共有 → 「ホーム画面に追加」でPWA利用。UIキャッシュによるオフライン表示と保存済み音声のオフライン再生（一度保存した履歴が端末に残っている場合）
- アイコン180/192/512pxを設定

## 注意
- iPhone Safariのメディア自動再生制限により、合成直後の自動再生が拒否されることがあります。その場合、表示される「▶ 再生」をタップしてください。
- クラウドAPIの応答待ちや429で読み上げが遅れたり失敗する可能性があります。即時読み上げを保証できません。
- 保存したWAVはSafari側でサイトデータを消去すると失われます。必要な音声は「WAV保存」で「ファイル」に保存してください。
- クラウド版は音程・抑揚のパラメーター指定を受け付けないため、その操作は自前エンジンモードのときだけ表示します。
- このPWAの画像は独自制作した豆のスイッチマスコットであり、公式のずんだもん立ち絵ではありません。

## 運用
```bash
npm install
npm test
npm run build
npm run dev
```
GitHub `iwamotoco-source/zunda` の `main` にpushするとVercelへ自動デプロイ。
Vercel Functions: `/api/speak`（TTS Questへの合成リクエスト）、`/api/audio`（許可リスト化されたaudioN.tts.questからの音声取得）。
第三者が無制限に呼べる公開APIとしての大規模利用は想定していません。
